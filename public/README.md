# Profile & Showcase Images Guide

## 1. Profile Photo (`/pradeep.png` or `/profile.png`)
- Place your portrait image in the `public` folder as `pradeep.png` or `profile.png`.
- Displays on the **Hero** section (in "Cyber Profile" mode) and in the **About** section with the glowing gradient border animation!

## 2. UI Flow Solution Showcase (`/ui_solution.png`)
- Place your UI mockup image in the `public` folder as `ui_solution.png`.
- Displays on the **Hero** (first page) in "UI Flow Solution" mode with glowing orbit rings, micro-floating widgets, and 3D flow animations!

## 3. Switching Modes
- On the first page, toggle between **UI Flow Solution** and **Cyber Profile** using the interactive glassmorphic pill switch.
